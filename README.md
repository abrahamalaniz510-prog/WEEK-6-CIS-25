# WEEK-8 CIS 25
This code is a bank account simulation
I started this one by making sure that we are given a fixed value at the start of our interaction with the code to emulate how it is when we log into our bank accounts
It then asks for a deposit 
After this, it asks for two different purchases that we have made.
It asks for variables and user input to see what the item is and then it asks for the cost of each item
It takes the user input and if it is applicable to our code, it will move onto the next part
Otherwise, if the cost exceeds the balance amount, it tells us that we have an insufficient balance available
After two inputs, it outputs our final balance
I did it this to way to make the person who goes through the code understand what goes on behind the scenes when we do simple things like this and bring understanding
